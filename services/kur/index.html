Program Kurus

Di Klinik Awfa, KotaSAS, Program Pengurusan Berat Badan kami direka untuk membantu anda memahami cara makan, bergerak, dan mengurus stres. Pilih program dengan atau tanpa bantuan ubat. Mulakan perjalanan penurunan berat badan anda hari ini!

Soalan lazim

Adakah saya wajib mengambil ubat?
Tidak. Anda boleh menjalani program tanpa ubat.
Berapa cepat saya boleh turun berat?
Kadar penurunan berat berbeza bagi setiap individu.
Saya tidak suka exercise. Bolehkah saya sertai?
Boleh. Program akan disesuaikan dengan kemampuan anda.
Adakah program ini sesuai untuk saya yang sering gagal diet?
Ya, program ini membantu mengenal pasti punca kegagalan diet sebelum ini.
